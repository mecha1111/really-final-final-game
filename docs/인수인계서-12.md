## 1. 튜토리얼 재구성

### 배경
기존은 말풍선 5쪽을 읽는 방식이었다. 읽고 넘기는 것뿐이라 학습이 안 됐다.

### 변경
스포트라이트 + 실제 시연 방식으로 전면 교체.

**흐름**
```
[게임 시작] → 렉 연출(업데이트 중 → 멈춤) → 강아지 등장 → 5단계 → [업데이트 재개] → 실전
```

**5단계**
| 단계 | 내용 | 진행 방식 |
|---|---|---|
| 1 | 목표 — 할당량 창 / 파일 진행바 순서로 스포트라이트 | [다음] |
| 2 | 시연① basic 소환 → 클릭해서 처치 → +MB 플로트 | 행동 완료 |
| 3 | 시연② ransom 소환 → 여러 번 클릭 | 행동 완료 |
| 4 | 방치 강제 → 실제 주기공격을 맞아 진행바가 깎임 | [다음] |
| 5 | 시연③ bait 소환 → 안 죽는 놈. 제한시간 설명 → 종료 | [업데이트 재개] |

### 구현상 중요한 것

**스포트라이트**
- `box-shadow: 0 0 0 9999px rgba(0,0,0,.72)` 로 구멍을 뚫는다. `filter` 금지
- `#desktop` 안의 `absolute` 형제. `position:fixed` 금지
- 좌표는 `rect ÷ 배율`. `offsetLeft` 사슬은 대상 자신의 `transform:translate(-50%)`를 못 봐서 215px/130px 어긋났다
- 캔버스 대상은 논리 x/y가 아니라 **그리기 좌표 `drawX/drawY`**를 써야 한다 (등장 연출 중 어긋남)
- 적을 따라갈 때는 0.26s 전환을 꺼야 한다. 안 그러면 영원히 뒤쫓는다

**4단계**
- `damageUpload`를 직접 부르지 않는다. 그 적의 `pendingAttack` 동결을 풀어 **실제 공격을 맞게** 한다
- 그래서 `ATK_WARNING` → `HIT`이 실전과 동일하게 난다. 예비동작 학습이 공짜로 붙는다
- 깎인 분량은 복구하지 않는다 (복구하면 교훈이 무효)

**게이팅**
- 튜토리얼 중 타이머 정지, 일반 스폰 정지, hazard 차단
- 시연 적은 위치 고정, `age`·`pendingAttack` 동결
- 오버레이는 `pointer-events:none`, 말풍선·건너뛰기만 `auto`

**흐름 전환**
- 기존에는 `phase === 'title'`인 채로 오프닝이 돌았다 (판을 아직 시작하지 않음)
- 새 설계는 진행바·할당량이 살아있어야 해서 `startGame()`을 먼저 부르고 그 위에서 오프닝을 돌린다
- 그래서 게이팅과 흐름 전환은 **반드시 같은 커밋**이어야 한다

### 이후 추가 수정
- 1단계 할당량 설명 중 실제로 `state.uploaded`가 오르게 함 (1MB/s, 3초)
- [다음]/[업데이트 재개] 버튼 씹힘 수정 — 원인은 `syncButton()`/`spotToRect()`가 매 프레임 `textContent`·`style.*`를 무조건 다시 쓴 것. 변경 감지 메모이제이션 추가
- 튜토리얼 종료 시 파일을 새로 잡아 `progress`를 0으로 시작. `state.uploaded`는 유지
- 문구 전면 존댓말 정리

### sfx
| 지점 | 배정 |
|---|---|
| 강아지 등장 | `SFX.UI_OPEN` (기존 그대로) |
| 시연 적 등장/처치 | 추가 코드 없음 — 실전과 동일하게 자동 재생 |
| 4단계 피격 | `ATK_WARNING` + `HIT` (실제 공격 경로) |
| 완료 → 실전 | `SFX.START` (튜토리얼 중에는 억제, 이 시점으로 이동) |

[다음] 버튼 클릭음·스포트라이트 이동음·단계 전환음은 넣지 않는다.

## 3. 밸런스 재설계

### 진단
붕괴 원인은 수치가 아니라 두 가지였다.

1. **밀도** — 방해꾼 12종 + 환경 6종 = 18개를 5구간에 넣어 구간당 3.6개씩 신규 등장
2. **손익분기** — 대형 파일 진행 2.50%p/s 대 마리당 피해 0.55~1.1%p/s → 손익분기 4~5마리인데 동시 상한이 11~14였다

### 등장 스케줄 축소
본편에 나오는 것 = **방해꾼 7종 + 환경 방해 2종**.

```
구간1 : basic
구간2 : + ransom, bait, popup
구간3 : + [환경] screensaver
구간4 : + bomb, clone
구간5 : + unplug, [환경] flip
```

무한 전용으로 이동: `fake_btn` `hourglass` `hidden` `copier` `zombie` / `reboot` `powersave` `driver` `cracked`

신규 종류는 그 구간 시작 후 15초 안에 **단독으로** 먼저 1마리 등장한다.

### 최종 수치
| 항목 | 값 |
|---|---|
| `FINITE_QUOTA_OVERRIDE` | `{0:183, 1:153, 2:196, 3:200, 4:173}` |
| `FINITE_MAX_ALIVE` | `[4, 4, 5, 6, 6]` |
| `FINITE_TYPE_CAP` | `[1, 3, 3, 3, 4]` |
| 스폰 간격 | `balance.csv` normal 0.8 → 0.92 (×1.15), `minSpawn` 0.6 → 0.69 |
| `atkDamageScale` | 0.55 — **건드리지 말 것** |

quota가 내려가는 곡선인 것은 의도된 것이다. 소요시간 목표를 우선했기 때문.
플레이어는 quota 숫자를 구간 간에 비교하지 않는다.

### 도중에 잡은 버그

**시트 드리프트**
구글 시트가 여전히 옛 quota를 서빙 중이라, 로컬 CSV만 고치면 타이틀에 5초만 있어도 조용히 원복된다.
기존 `enemyUnlockPlan`/`applyEnemyUnlockPlan()` 패턴을 따라 `quotaOverride`/`enemyWeightOverride` + 적용 함수 추가로 방어.

**clone 분열이 상한을 우회** (커밋 `86bd4b5`)
`stageManager.js`의 `state.enemies = keep.concat(born)` — 분열 자식이 `spawner.update()`를 안 거쳐 마릿수·종류·개별 상한 3개를 전부 통과했다.
실측: 4구간 표기 6 → 최대 10, 400판 중 95%에서 초과.
`splitEnemy()`에 `cap` 인자 추가로 수정.

**상한 기준 불일치** (커밋 `3fc312f` → `a8786a1`)
스폰 게이트가 시체까지 세고 있었다. `.alive` 기준으로 통일했더니 1구간 초심자가 43% → 17%로 반토막.
시체가 0.16~0.35초씩 슬롯을 물던 것이 사실상 스로틀이었다.
→ `killSlotHoldSec` / `killSlotHoldBasicSec`를 **명시적 파라미터로 신설**해 복원 (커밋 `19f2ea6`).
부활 대기 zombie는 계속 슬롯을 차지한다 (`countsForConcurrency`).

## 5. Electron exe

브랜치 `desktop-exe` (기준 `3faab9c`). 커밋 4개.

| 커밋 | 내용 |
|---|---|
| `e2c5760` | Electron 셸 + `app://` 스킴 |
| `8e98c2b` | 오프라인 — 시트 fetch 게이팅, 리로드 버튼 숨김 |
| `95bff6a` | 포터블 exe 패키징 |
| `81bf806` | 아이콘 재작업 |

### 핵심

**`file://` 쓰지 말 것.** ES 모듈 import·JSON fetch·localStorage가 전부 깨진다 (세이브 소실).
`app://`를 standard·secure 스킴으로 등록하고 파일은 `fs`로 읽는다.

**전체화면은 네이티브 `win.setFullScreen(true)`로.**
DOM `requestFullscreen()`은 ESC로 해제되고 `before-input-event`로도 못 막는다 (실측 확인).
네이티브 방식은 ESC에 안 깨지고, 페이지는 keydown을 정상 수신해 설정창이 열린다.
`settingsPanel.js`의 전체화면 체크박스는 Electron에서 IPC로 라우팅한다.

**기타**
- 전체화면 시작, F11 창 전환, 메뉴바 제거, devtools 비활성, 창 최소 960×540
- 시트 fetch는 `loadFromSheets()` 한 곳만 게이팅하면 3개 호출부가 전부 막힌다
- 설정창 수동 새로고침 버튼은 데스크톱에서 숨김
- `platform.js`에 `isDesktopApp()`/`quitApp()` 훅이 이미 있었다
- 아이콘: 로고 전체가 아니라 폴더 도형만 + 빨간 X 배지. 16/32px은 별도 단순화 SVG
- 파일명·`productName`·`artifactName` 전부 NFC 정규화 (macOS는 NFD로 저장)

### 산출물
```
release/진짜_최종_final_수정_진짜최종(5).exe   161MB (portable)
release/win-unpacked/                          503MB
```

macOS에서 Wine 없이 크로스 빌드가 실제로 됐다.
**단, Windows에서의 실행 검증은 아직 안 됐다.**
