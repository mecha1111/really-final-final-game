    2 · Office 길잡이 말풍선 — 실물 구조로 정정

    MS 문서로 확인했다. 말풍선이 캐릭터 위에 뜨고, 버튼 2~3개가 말풍선 안 아래쪽에 들어간다. 버튼 세트는 정해져 있다 — Back·Next·Close, Tips·Options·Close, OK 등. 본문은 굵은 Heading + 파란 원 불릿 목록. 팁이 있으면 캐릭터 위에 노란 전구가 깜빡인다. 말풍선 바깥을 클릭하면 닫힌다.
    앞서 버튼을 강아지 옆에 뒀던 건 잘못이었다.

    4 · 컨트롤

    초록 대화상자 버튼은 XP에 없다. 초록은 시작 버튼 전용. 눌림은 그라데이션 반전 — 색이나 위치를 옮기지 않는다. 폼 요소엔 font-family:inherit를 반드시 붙일 것.
    XP 진행바는 분절 블록이다. 연속 채우기가 아니다.

    6 · 아이콘 — 단색 SVG만

    viewBox 0 0 16 16, stroke-width 0.9~1.4, 정수/반정수 좌표 정렬. 필터·그라데이션 안 씀. 게임에선 ui/icons.js의 icon(name,size)로 꺼내 쓴다.

    7 · 하지 말 것

    1. 움직이는 내용 위 전체화면 filter 금지. 랜딩에서도 SVG 색분리를 걸었다가 렉으로 제거한 이력이 있다. CRT 효과는 형제 오버레이 + pointer-events:none + 정적 그라데이션으로만.
    2. 작업표시줄·오버레이를 fixed로 두지 말 것. 부모 transform이 기준을 깨뜨린다. 화면 컨테이너 안 absolute 형제.
    3. 표시/숨김에 hidden 속성 금지 — display:flex 규칙에 특이도로 밀린다. .on/.open 클래스 토글.
    4. transform으로 축소된 좌표계 안에서 vh 금지. 두 기준이 섞인다.
    5. DGM 한글은 11px 미만에서 자소가 뭉갠다. 도감에서 "처치"가 "저지"로 읽힌 전례가 있다. 읽을 문장은 15px.
    6. 다수 개체 이동에 left/top 금지. transform:translate()로.
    7. 폼 요소에 font-family:inherit 빠뜨리지 말 것. 브라우저 기본 폰트가 튀어나온다.
    8. 헤드리스 브라우저 fps는 GPU가 없어 CPU 래스터라 의미 없는 숫자다. 성능 판단은 실제 GPU에서만.
