6 · 스포트라이트 — 지킬 것

1. 구멍은 box-shadow: 0 0 0 9999px rgba(0,0,0,.72)를 건 빈 요소로 뚫는다. filter/backdrop-filter/mask 전부 금지 — 어둠을 깔고 지우는 게 아니라 구멍 말고 전부를 칠한다.
2. position:fixed 금지. 무대(게임에선 #desktop) 안의 absolute다. 부모가 transform으로 축소돼 있어도 기준이 안 흔들린다.
3. 모서리 radius:0. 테두리는 흰 1px + 그 안쪽 검은 점선 1px — XP 포커스 사각형 그대로다. 점선은 box-shadow로 못 그리므로 안쪽에 요소를 하나 더 쓴다.
4. 레이어 전체 pointer-events:none. 시연 단계에서 캔버스 클릭이 살아있어야 한다 — 한 톨이라도 먹으면 "적을 클릭해라"가 성립하지 않는다.
5. 표시/숨김은 .on 클래스. hidden 속성 금지 (display가 박힌 규칙에 특이도로 밀린 전례가 두 번).
6. 단위는 px 고정. vh 금지 — 무대는 뷰포트가 아니라 자기 고정 좌표계를 산다.

★좌표 함정 — 여기서 반드시 틀린다. getBoundingClientRect()는 transform으로 줄어든 값을 준다. 그대로 넣으면 구멍이 배율만큼 작게, 왼쪽 위로 밀려 그려진다.
· HTML 대상 — rect ÷ 무대 배율. 배율은 (표시 폭 / 레이아웃 폭)으로 잰다.
  ★offsetLeft 사슬로 가면 틀린다 — 대상 자신의 transform을 못 본다. translate(-50%)로 가운데 정렬한 요소(렉 창·로고)에서 실측 215px / 130px 어긋났다. rect는 transform까지 반영한 최종 위치라, 배율로 나누기만 하면 맞는다.
· 캔버스 대상(방해꾼) — 논리좌표 × (무대 폭 / 캔버스 논리 폭). 게임에선 1920 / config.canvas.width이고 이건 getUiScaleFactor()의 역수다. 두 값이 다 알려져 있어 잴 이유가 없다.
위 [방해꾼(캔버스 좌표)] 버튼이 그 환산을 검사한다 — 초록 원과 구멍이 같은 환산을 쓰므로, 어긋나면 그 자리에서 바로 보인다.
