XP 파일 아이콘 (아이소메트릭) + 화면 깨짐

XP 아이콘의 정체는 "평면 다색"이 아니라 비스듬히 본 입체다. 정면 평면으로 그리면 색을 아무리 넣어도 현대적으로 보인다.
★그라데이션은 파일 아이콘에만 허용 — linearGradient는 filter가 아니라 합성 비용이 사실상 0이고, XP 입체감이 전적으로 여기서 나온다. (UI 크롬 아이콘은 여전히 단색·그라데이션 금지)

1 · 평면 vs 아이소메트릭

왼쪽은 정면 평면 — 색은 다색인데도 "현대 플랫 아이콘"으로 읽힌다.
오른쪽은 XP 실물 방식 — 기울어진 면 + 두께 + 그라데이션 음영 + 아래쪽 그림자.

✕ 정면 평면

✓ 아이소메트릭 (XP)

2 · 우리 게임 앱 아이콘

바탕화면에서 이것만 찾아야 하는 아이콘이다. 주변이 노란 폴더·흰 문서라 파란 창 + 초록 진행바면 색만으로 즉시 눈에 띈다. 기울어진 XP 창 + 진행바 — 16px에서도 "파랑 위 초록 막대"가 유지된다.

5 · 화면 깨짐 — 세로 픽셀 열 고장

노이즈 사각 블록은 "고장난 모니터"가 아니라 그냥 노이즈다. 실물 패널 고장은 세로로 한 줄이 통째로 죽거나 색이 튄다.
★구성: 세로 열 2~4개(폭 3~8px, 화면 관통) + 각 열의 성격이 다름 — 죽은 열(검정) / 박힌 열(흰색) / 색 튀는 열(RGB가 계속 바뀜). 여기에 CRT 어휘로 ★수평 지직 밴드를 가끔 얹는다.
드래그로 문지르면 열 단위로 지워진다.

★화면 위를 드래그하면 열이 지워집니다

★전조: 발동 1초 전에 세로선 하나가 짧게 번쩍했다 사라진다. "무엇이 오는지"는 알려주되 막을 수는 없다 — 전조는 그 효과의 축소판이다.

6 · 하지 말 것

1. 파일 아이콘에 currentColor 금지. 지금 버그의 원인이다.
2. UI 크롬 아이콘과 파일 아이콘을 ★같은 함수로 꺼내지 말 것. 계약이 다르다.
3. 정면 평면으로 그리지 말 것. 색이 아니라 ★시점이 XP다움을 만든다.
4. filter: drop-shadow 금지 — 그림자는 도형으로 흉내낸다.
5. 화면 깨짐을 랜덤 노이즈로 만들지 말 것. ★세로 열이어야 고장으로 읽힌다.
6. 깨짐 캔버스를 매 프레임 다시 그리지 말 것 — 열이 바뀐 프레임에만.
